### 接口约束

- 四路驱动芯片为AT8236，每路使用两路PWM。C/D的逻辑PWMC1/PWMD1对应CH2/CH4，不能凭表格顺序推断方向。
- USB串口1的DTR/RTS接入NRST和BOOT0下载电路；建议运行通信使用USB串口3，串口1保留调试/下载。
- Type-C还包含供电接口，必须按丝印识别；不能将供电口当作数据口。
- PD3连接软件输入，不能视为独立切断电机电源的硬件急停。
- 原理图未见四路电流测量回接MCU的链路；AT8236的ISEN电阻不等于可上报的电流传感器。
- IMU存在板载电平转换；不能将ICM20948器件侧电平直接等同于MCU侧电平。
- USB供电路径、Jetson供电和电机供电需要实机核对，不能仅凭接口名称判断整机供电能力。

## 3 电机控制示例

基础PID示例：[S3]中的`07-电机闭环控制例程/PID.zip`，重点文件为`USER/main.c`、`WHEELTEC_BSP/bsp_motor.c`、`bsp_encoder.c`。

| 项目 | 示例实际行为 | 状态 |
| --- | --- | --- |
| PWM | 10kHz，ARR=16799，PSC=0 | 资料确认，依赖示例时钟树 |
| TIM7 | 200Hz中断 | 资料确认 |
| 编码器与PI | 中断分频后100Hz执行 | 资料确认；不能照抄注释中的200Hz |
| IMU更新 | 每次TIM7中断执行 | 资料确认 |
| 编码器读取 | CNT转short后清零 | 资料确认；项目需改进 |
| PI | 四路独立增量PI，输出限幅 | 资料确认 |

增量PI：`u[k] = u[k-1] + Kp*(e[k]-e[k-1]) + Ki*e[k]`，其中`e=目标轮速-测量轮速`。控制频率改变后需重新整定，不能保留原Ki而假定响应不变。

编码器换算：

```text
N_wheel = 减速比 × 编码器每转线数 × 解码倍频
rpm = Δcount / N_wheel / Δt × 60
v = Δcount / N_wheel / Δt × 2πr
```

该公式要求线数定义与编码器安装轴一致。若厂家已给输出轴倍频后计数，不得再次乘减速比或4。

基础示例默认使用`30×13×4`；GMR整车代码使用`Photoelectric_500`。这些属于示例值，不是已确认的MG513实车参数。[S3][S4]

### NavBot拟采用的运动学

```text
v_left  = vx - b_eff*wz/2
v_right = vx + b_eff*wz/2
```

同侧两轮目标一致、四路独立闭环。`b_eff`是有效轮距，需通过转向实测标定。普通四轮滑移转向的误差随地面、载荷变化，几何轮距只作为初值。

厂家GMR代码四驱分支使用`(Wheel_spacing + Axle_spacing)`作为转向系数，并将A/B作为左侧、C/D作为右侧。项目不能直接继承这一系数和接线假设。[S4]

项目改进项（设计建议）：

- 自由运行计数器配合模差分，避免读后清零窗口丢脉冲；根据最大转速验证单周期计数不产生多义回绕。
- 维护累计计数，并以一致快照输出；Cortex-M4上的64位共享数据需要保护，不能只依赖volatile。
- 配置电机方向和编码器方向，验证正反馈风险后再闭环。
- 失联、禁止、故障时清除PI状态和旧目标；增加斜坡限速和积分饱和处理。
- I²C、显示和通信不在关键控制路径中进行无界等待。

## 4 IMU与DMP示例

MPU6050示例流程：[S5]中的`HARDWARE/MPU6050/MPU6050.c`、`HARDWARE/DMP/inv_mpu.c`。

```text
软件I²C → 识别芯片 → 配置加速度/陀螺仪
→ 加载DMP → 配置安装方向 → 200Hz FIFO
→ 角速度、加速度、Q30四元数 → 欧拉角
```

已核对的限制：

- `Read_DMP()`未检查`dmp_read_fifo()`返回值，未完整处理FIFO积压和溢出。
- `get_ms`映射的`myget_ms()`为空，不能直接采用示例时间戳。
- 安装矩阵固定为`diag(-1,-1,1)`，必须按实物重新确定。
- 四元数为Q30，除以2^30后得到浮点值；示例欧拉角命名不能直接当作ROS轴定义。
- 六轴姿态不能提供长期无漂移的绝对航向。

### 新版ICM20948

实际驱动应以新版ICM20948示例为基础，而不是烧入MPU6050 DMP驱动。[S3]

- 示例读取加速度、角速度、磁力计，但`attitudeUpdate()`实际使用陀螺仪和加速度计做互补融合，不具有磁北约束。
- 加速度寄存器配置为±2g，转换系数约0.0005981 m/s²/LSB；附近“±8g”注释与代码不符，应以寄存器和实测为准。
- 陀螺仪配置为±2000°/s，转换为rad/s。
- 示例将`abs(gyro.z)<0.05 rad/s`置零，会丢失缓慢转向信息；导航固件拟取消该硬死区，用静态偏置标定和滤波替代。
- 算法时间步固定为5ms；项目应使用有效采样周期，并验证传感器ODR、读取频率和时间戳关系。

| 数据 | 来源 | 使用边界 |
| --- | --- | --- |
| 轮速和行程 | 编码器 | 里程计主输入；打滑时有误差 |
| 三轴角速度和加速度 | IMU | 统一单位、轴向、有效性 |
| Roll/Pitch | 姿态估计 | 倾斜监测；需安装标定 |
| Yaw | 相对姿态估计 | 漂移，不能替代地图定位 |
| 地图位姿 | Jetson上的SLAM/定位 | 全局定位 |

不得以加速度积分作为主要底盘线速度。初期EKF优先融合轮式速度和IMU Z轴角速度；不把同源姿态、角速度或编码器位姿当作独立测量重复加权。
