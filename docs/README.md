## 参数状态约定

- **用户确认**：用户提供的实车配置；不等于已读取设备或完成测试。
- **资料确认**：原理图或示例源码中已核对；仍需确认实物版本和接线匹配。
- **设计建议**：本项目拟采用的方案，尚未冻结或验证。
- **待实测**：需要在实物或运行系统上测量、读取或标定。
- **待定**：需要在编码前明确的设计细节。

协议 v0.1 为讨论草案，不能作为已经冻结的逐字节实现规范。后续修改应同时维护参数状态和来源。
