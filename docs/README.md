## 证据与版本约定

- **已实现**：在锁定提交的源码中存在；不自动意味着实机已验收。
- **已实测**：必须说明版本、工况和结果。架空测试不能替代落地负载验证。
- **用户提供 / 资料确认 / CAD名义值**：用于实现初值，不替代独立标定。
- **待实现 / 待标定**：属于后续工作，不作为当前能力宣传。

主仓库介绍当前可用范围；精确参数和帧布局以子模块源码及运动协议为准。固件1.1.2、线上协议帧version=1和硬件归档1.2.0是不同版本标识。

旧协议草案和已完成的实施步骤已从当前说明中移除，历史内容可通过Git历史查看。硬件release文件和固件历史验收记录保留其原始日期与版本，不能当作当前整机验收结论。
